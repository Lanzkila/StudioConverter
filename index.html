ABOUT MANGA STUDIO PRO

Manga Studio Pro is a local-first manga toolkit. Files are processed inside your browser; the dashboard stores only local conversion history, thumbnails and dashboard preferences.

Supported workspaceCBZ, ZIP, PDF and common image formats, with conversion, page tools, metadata and repair functions in the existing converter.
Dashboard 3.0Recent conversion library, pinned and favourite items, details, pagination, local backup/import, activity and browser status.
Privacy modelNo account is required by this theme and dashboard history stays in browser storage unless you explicitly export it.
CHANGELOG
Dashboard 3.0Pin/favourite history, details drawer, Grid/List modes, pagination, JSON backup/import, measured space saved, monthly summary, About/Changelog and mobile polish.
Dashboard 2.0Premium Recent Conversions, search/filter/sort, statistics, local cache information, browser status and activity timeline.
Dashboard 1.0Dashboard landing page, Recent Conversions with thumbnails, information cards and automatic footer year.
